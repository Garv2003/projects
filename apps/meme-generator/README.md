# meme-generator

Search a library of meme templates, add text overlays, and save your favourites.

- Next.js 15 (App Router) + Tailwind + Radix UI
- Auth: NextAuth (Google sign-in)
- Database: Postgres on Neon via Drizzle ORM
- Image upload / hosting: ImageKit

## Run

```bash
cp .env.example .env   # fill in the values
pnpm install
pnpm dev
```
